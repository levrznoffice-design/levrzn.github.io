Немецкий — каждый день параллельно

Уроки с учителем остаются. Добавляешь: когда изучаешь тему —
гуглишь её же на немецком и читаешь один абзац.
Строит технический словарь постепенно.

Spaced Repetition — Интервальное повторение

Day 1
Изучаешь новое. Мозг впервые видит информацию.
Day 2
Первые 10 минут — повторяешь вчерашнее. Потом новый материал.
Day 7
Повторяешь всю неделю за 15 минут. Закрепляешь в долгосрочную память.
Это единственный способ реально запомнить. Без повторения — 90% забывается за неделю.

Темы для изучения

#1
SQL — Недели 1–4
Три модуля первого года завязаны на SQL. Самое важное.
Что гуглить: SQL для начинающих, что такое база данных таблица, SQL SELECT WHERE JOIN объяснение
Цель: создать таблицу, вставить данные, достать их запросом, соединить две таблицы через JOIN
⏱️ 1 час видео + 1 час практика каждый день
💻 SQLBolt 💻 SQLZoo
#2
Schnupperwoche — Неделя 5
20–24 апреля — наблюдение в школе
Дома не учишься. Только наблюдаешь, задаёшь вопросы студентам.
#3
Программирование (Python) — Недели 6–9
Модуль 319 — первое программирование в школе. Язык не важен, важна логика.
Что гуглить: программирование с нуля, что такое переменная, условия и циклы, функции для чего
Цель: программа-приветствие, счётчик от 1 до 100, программа с если/иначе
⏱️ 40 мин видео + 40 мин код каждый день
💻 Replit 💻 futurecoder.io
#4
Сети — Недели 10–12
Модуль 117 — строишь офисную сеть
🇷🇺 как работает интернет, что такое IP адрес, роутер и свитч разница, DNS, OSI модель
🇩🇪 IP-Adresse erklärt, Router Switch Unterschied, OSI-Modell einfach erklärt
Цель: понять что происходит от нажатия Enter до загрузки сайта
⏱️ 1 час в день
🎬 Wie funktioniert das Internet
#5
Компьютер и ОС — Недели 13–14
Модуль 187 — PC собрать и настроить
Что гуглить: материнская плата процессор RAM, что такое ОС, Linux и Windows разница, командная строка
Цель: выучи команды cd, dir, mkdir, ping — открой командную строку и попробуй
⏱️ 1 час в день
#6
Java синтаксис — Недели 15–16
Модуль 320 второго года — ООП на Java. Просто снять страх.
Что гуглить: Java для начинающих первая программа, разница Python и Java, что такое класс в Java
Цель: написать одну программу Hello World на Java
⏱️ 1 час в день

Почему именно это

SQL используется в каждом году из четырёх.
Программирование — непрерывная линия от 319 до 321.
Немецкий — весь ABU и все экзамены на нём.

Это три вещи которые влияют на все четыре года. Остальное школа даст сама в нужное время.
